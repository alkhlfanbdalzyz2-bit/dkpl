# طريق التطور والاتزان (D-K-P-L)

تطبيق ويب تقدّمي (PWA) لمتابعة المهام اليومية في أربعة أركان: الروح والإيمان، العلم والتطوير، الإنتاج والبناء، العادات والصحة.

- اليوم يمتد من الفجر إلى الفجر (حساب فلكي تلقائي أو وقت يدوي).
- نقاط خبرة ومستويات، وعدّاد أيام متتالية، ومهام جانبية، وعدّاد ماء.
- البيانات محفوظة في المتصفح، مع تصدير واستيراد نسخة احتياطية (JSON).

التشغيل: افتح `index.html` من أي استضافة (GitHub Pages / Netlify) ثم «إضافة إلى الشاشة الرئيسية».
